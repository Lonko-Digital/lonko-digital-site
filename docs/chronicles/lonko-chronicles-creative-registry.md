# Lonko Chronicles — Creative Registry

**Canonical repository location:** `docs/chronicles/lonko-chronicles-creative-registry.md`.

**Authority:** This repository copy is the single source of truth (synced from Claude Blog by Cursor Web on 2026-09-19). Claude.ai Project mirrors are working copies only and must be checked against this file.

Living record of **approved** hero, social, and banner creative for Lonko Chronicles, governed by the Visual Creative System in `docs/chronicles/lonko-chronicles-operating-system.md` §57. Read this before developing new concepts (§57.16, step 3) to check what's been done recently and avoid repeating the same scene DNA.

**This registry records approved creative only** — not discarded concepts, rejected drafts, or in-progress rounds. A concept round that produces three candidate worlds and Alex picks one gets exactly one entry: the one that was approved.

**Format note:** built as a flat markdown table by design so it can move cleanly into Google Sheets later — one row per creative, one column per field, no merged cells or nested structure. When that migration happens, this table exports directly; no rework needed.

**Creative ID convention:** `CR-0001`, `CR-0002`, ... sequential, never reused, assigned at the time of approval (not at concept-drafting time, since not every concept gets approved).

## Field definitions

| Field | What goes here |
| --- | --- |
| Creative ID                          | Sequential `CR-####`, assigned on approval                                                                                                                                                                                                                                                                                                                                                                              |
| Article / Campaign                   | The article title or campaign name this creative belongs to                                                                                                                                                                                                                                                                                                                                                             |
| Article slug                         | The Chronicles URL slug, once it exists                                                                                                                                                                                                                                                                                                                                                                                 |
| Date approved                        | Date Alex approved this specific asset                                                                                                                                                                                                                                                                                                                                                                                  |
| Asset type                           | `hero` / `social` / `in-body chart` / `other banner`                                                                                                                                                                                                                                                                                                                                                                    |
| **Dimensions / aspect ratio**        | Production dimensions and ratio, e.g. "1200×630 — 1.91:1", "1600×900 — 16:9", "1080×1080 — 1:1". Hero, social, and structured-data assets often need different production requirements — record what was actually produced, not a generic default.                                                                                                                                                                      |
| Topic                                | Short topic label, matching the article's primary topic                                                                                                                                                                                                                                                                                                                                                                 |
| Topic signal                         | What in the image ties it to this specific article (§57.2)                                                                                                                                                                                                                                                                                                                                                              |
| Visual territory                     | Professional / emotional-outcome / mixed (§57.6-57.7)                                                                                                                                                                                                                                                                                                                                                                   |
| Environment                          | e.g., "mountain campsite," "conference hallway," "retail counter"                                                                                                                                                                                                                                                                                                                                                       |
| Geographic / environmental feel      | General regional/environmental character, not a literal claimed location (e.g., "coastal," "urban downtown," "rural/countryside")                                                                                                                                                                                                                                                                                       |
| People configuration                 | e.g., "solo executive," "family of four," "owner + employee"                                                                                                                                                                                                                                                                                                                                                            |
| Representation                       | Broad description only (e.g., "Black woman, 40s"), never used to force a pattern — see §57.4. No sensitive personal data — this describes the *image's subject*, a stock/generated figure, never a real named individual.                                                                                                                                                                                               |
| Approx. age/life stage               | Where useful — e.g., "mid-career," "young family," "near-retirement"                                                                                                                                                                                                                                                                                                                                                    |
| Activity                             | What's happening in the frame                                                                                                                                                                                                                                                                                                                                                                                           |
| Primary device                       | mobile / tablet / laptop / desktop / presentation display / none                                                                                                                                                                                                                                                                                                                                                        |
| Secondary device                     | If a second device appears, or "none"                                                                                                                                                                                                                                                                                                                                                                                   |
| Emotional theme                      | From §57.6 (relief, confidence, freedom, etc.)                                                                                                                                                                                                                                                                                                                                                                          |
| Business outcome theme               | From the customer-promise list in the operating system doc §2                                                                                                                                                                                                                                                                                                                                                           |
| Composition style                    | e.g., "candid documentary," "considered editorial portrait," "wide environmental"                                                                                                                                                                                                                                                                                                                                       |
| Time of day                          | If relevant to mood/lighting                                                                                                                                                                                                                                                                                                                                                                                            |
| Season                               | If relevant                                                                                                                                                                                                                                                                                                                                                                                                             |
| Visual metaphor                      | If one is used (use sparingly per §57.10 restraint)                                                                                                                                                                                                                                                                                                                                                                     |
| Headline approach                    | For social banners: whether/how text is treated on the image itself                                                                                                                                                                                                                                                                                                                                                     |
| Brand treatment                      | How Lonko identity appears (logo, color system, wordmark, none)                                                                                                                                                                                                                                                                                                                                                         |
| **Rights / provenance / license**    | Where the image came from and its usage status — e.g., "AI-generated internally," "commissioned photography," "licensed stock — [source/license reference]," "internally produced photography," "client-provided asset with permission," "other verified provenance." Kept as its own field, not buried in production notes, so Lonko can always answer "where did this come from, and do we have the right to use it?" |
| Image-generation / photography notes | Production notes — prompt summary, tool used, revision notes. (Provenance/rights lives in its own field above, not here.)                                                                                                                                                                                                                                                                                               |
| Reuse cautions                       | Anything future concept rounds should avoid repeating from this one                                                                                                                                                                                                                                                                                                                                                     |
| Final status                         | `approved` (this registry only tracks approved, so this should always read approved — kept as a field for the eventual Sheets migration, where a status filter may be useful)                                                                                                                                                                                                                                           |
| Asset filename/path                  | Where the file lives once produced                                                                                                                                                                                                                                                                                                                                                                                      |

**Privacy:** no sensitive personal information is recorded here. "Representation" fields describe imagined/generated or stock figures for creative-planning purposes, never a real, named, identifiable individual.
